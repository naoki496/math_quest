## さんすうクエストについて

**さんすうクエスト**は、算数学習とRPG的な世界攻略を組み合わせたブラウザゲームです。

単に計算問題を続けて解くだけではなく、世界ごとに主人公・舞台・敵・音楽・問題傾向・ボス戦の演出を変え、学習の進行そのものを冒険として楽しめることを目指しています。

HTML / CSS / JavaScript を中核として動作し、PC・タブレット・スマートフォンの画面に応じたレスポンシブ表示に対応しています。

## 基本ルール

- 問題は原則 **3択** です。
- 通常の制限時間は **1問60秒** です。
- **ライフは3**。誤答または時間切れでライフが減ります。
- 通常のステージは **通常問題10問 + BOSS戦5問** で構成されます。
- 一度BOSSへ到達すると、再挑戦時には通常問題を省略してBOSS戦から再開できます。
- 正解を重ねるとSPECIALゲージが増加し、戦闘を有利に進められます。

BOSS戦では、通常問題とは異なる固有の演出や特殊行動が発生することがあります。

## 世界と学習内容

物語の進行に応じて世界が解放され、扱う算数の内容も段階的に広がります。

| 世界 | 学習の目安 | 主な内容 |
|---|---|---|
| **光の世界** | 小学1年生相当 | 加法・減法を中心とした基礎計算 |
| **裏の世界** | 小学2年生相当 | 2桁の加減、簡単な3桁計算、九九など |
| **紅の世界** | 小学3〜4年生相当 | 割り算、小数、分数、四則混合など |
| **蒼の世界** | 小学5年生相当 | 小数の乗除、異分母分数、平均、速さ、割合など |
| **銀の世界** | 小学6年生相当 | 分数の乗除、比、円、比例・反比例など |
| **翠の世界** | 小学4〜6年生の応用 | 単位、面積、規則、場合の数、論理・条件整理など |
| **終の世界** | 既習算数の統合・発展 | これまでの世界の問題体系を再構成した高難度領域 |
| **白の世界** | ENDLESS CHALLENGE | 既存世界の問題を再構成し、DEPTH制で挑戦を継続 |

文章題については、対象学年から大きく逸脱しないことを重視し、生活場面や教科書に近い文脈を基本としています。

## 文章題

一部の問題では文章題が出題されます。

文章を丸暗記して答えられる固定問題だけにならないよう、文章テンプレートと制約付きの数値生成を組み合わせています。一方で、ランダム化によって単位・助数詞・計算条件や日本語が不自然にならないよう、問題生成時に条件を設けています。

BOSS固有の特殊問題など、演出や出題構造そのものに意味がある場面では、通常の文章題を混在させない設計です。

## ゲーム内機能

### まちがいノート

間違えた問題を端末内に記録し、あとから確認できます。同じ問題を繰り返し間違えた場合は回数も記録されます。

復習が済んだ問題は **「もう大丈夫」** として個別に外すことができます。

### コレクション / ショップ

ゲーム中に得られるゴルドを使ってアイテムを集められます。入手したアイテムはコレクション画面で確認でき、世界や物語に関係する記録を読むことができます。

### モンスター図鑑

遭遇したモンスターが図鑑へ登録されます。通常モンスターだけでなく、各世界のBOSSにも個別の記録があります。

### BGM鑑賞

ゲーム内で解放したBGMをタイトル画面から鑑賞できます。

### データ管理

世界の解放状況、コレクション、モンスター図鑑、まちがいノート、BGM、各種記録などは自動保存されます。ゲーム内の「データ管理」から保存状態の確認やセーブデータの削除ができます。

---

## セーブデータについて

セーブデータは、プレイしている**端末のブラウザ内**に保存されます。

そのため、別の端末や別のブラウザへ自動的に進行状況が同期されるものではありません。ブラウザのサイトデータを削除した場合などには、保存内容が失われる可能性があります。

正常なセーブについては、復旧用として1世代の自動バックアップを保持する仕組みを備えています。

## ローカルで確認する場合

本作は `index.html` / `styles.css` / `app.js` を中心とし、文章題データとして `word_questions.json` を使用します。

`word_questions.json` はブラウザから `fetch()` して読み込むため、**GitHub Pagesなどの HTTP / HTTPS 環境での実行を推奨**します。

`index.html` を `file://` で直接開いた場合、ブラウザのセキュリティ制限によってJSONの読み込みが拒否されることがあります。その場合もゲーム本体が停止しないよう、従来の計算問題へフォールバックする設計になっています。

主要構成：

```text
.
├─ index.html
├─ styles.css
├─ app.js
├─ word_questions.json
├─ assets/
└─ SPECIFICATION.md
```

`SPECIFICATION.md` は開発・実装上の詳細を確認するための資料です。READMEは一般利用者向けの案内を主目的としています。
